🌐 Kiểm tra trước khi đăng website (GitHub Pages)

⚠️ Tính năng đăng tự động: CHƯA HOÀN THÀNH.
Studio cục bộ KHÔNG tự động push remote hay kích hoạt deploy. Modal này đóng vai trò Kiểm tra trước khi đăng để đảm bảo an toàn trước khi người vận hành thực hiện commit và push thủ công.
Đang kiểm tra trạng thái Git repository...

ℹ️ Quy trình đăng an toàn (Chuẩn 6 bước):

  1. Cập nhật thư viện cục bộ: Bấm 🚀 Cập nhật thư viện để ghi dữ liệu vào songs.js kèm bản sao lưu.
  2. Kiểm tra dữ liệu ứng viên: Chạy node tools/validate-songs.mjs và node tools/report-text-qa.mjs.
  3. Commit riêng dữ liệu bài hát:
    git add songs.js
    git diff --staged (kiểm tra staging chỉ có đúng songs.js, không kèm file khác)
    git commit -m "data: update songs library"
  4. Sinh data-revision từ commit vừa tạo: Chạy npm run update:data-revision để cập nhật data-revision.js mang đúng SHA commit dữ liệu.
  5. Cập nhật phạm vi QA & Kiểm tra trạng thái cuối:
    • Cập nhật datasetRevision trong qa/text-qa-policy.json và qa/batches.json.
    • Nếu có thêm/xóa bài: Cập nhật qa/batches.json mở rộng/thu hẹp batch cuối để bảo đảm các batch phủ kín 100% thư viện (không chỉ đổi revision).
    • Chạy npm run check đảm bảo toàn bộ kiểm tra đều PASS.
  6. Commit metadata & Push lên GitHub:
    git add data-revision.js qa/text-qa-policy.json qa/batches.json
    git diff --staged (xác minh chỉ stage 3 file metadata đã kiểm tra)
    git commit -m "chore: sync data revision and qa metadata"
    git push origin main (GitHub Actions CI sẽ tự động build và deploy lên GitHub Pages).
