🚀 QUY TRÌNH SỬ DỤNG LIÊN TỤC:
1. Nạp dữ liệu gốc: Chọn file songs.js hiện tại của bạn vào ô màu vàng để nạp danh sách cũ.
2. Import file nhạc liên tục: Tải file .musicxml vào ô màu xanh lá để tự động bóc tách Lời 1 và Lời 2.
3. Lưu trữ tạm thời: Sửa đổi thông tin nếu cần thiết rồi bấm nút "Thêm / Cập nhật vào danh sách tổng".
4. Xuất file tổng hợp: Cuối phiên làm việc, chọn nút màu xanh lá để tải file songs.js mới về đè lên file cũ trên máy.
