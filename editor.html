Dự án Hợp Âm Thờ Phượng (HOPAMTHANHCA)

🚀 QUY TRÌNH SỬ DỤNG LIÊN TỤC:
1. Nạp dữ liệu gốc (Chỉ cần 1 lần duy nhất đầu phiên): Chọn file songs.js hiện tại của bạn vào ô màu vàng để nạp danh sách cũ.
2. Import file nhạc liên tục: Tải file .musicxml vào ô màu xanh lá. Hệ thống sẽ tự động quét bóc tách sạch sẽ Lời 1 và Lời 2 (giữ nguyên hợp âm đôi chuẩn xác).
3. Lưu trữ tạm thời: Kiểm tra phông nền, sửa đổi thông tin nếu cần thiết rồi bấm nút "Thêm / Cập nhật vào danh sách tổng". Form sẽ tự xóa trống để bạn chọn tiếp file XML tiếp theo.
4. Xuất file tổng hợp: Khi hoàn thành toàn bộ công việc, kéo xuống cuối trang chọn nút màu xanh lá để tải file songs.js mới về đè lên file cũ.
