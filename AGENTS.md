# Project continuity

Before planning or changing this repository, read `README.md` and
`docs/PROJECT_LOG.md`. The log is the durable handoff for the current state,
decisions, verification evidence, known issues, and next work.

After a substantive change, update `docs/PROJECT_LOG.md` in the same change.
Record what changed, the exact verification commands and outcomes, remaining
risks, and the next concrete step. Keep `songs.js` unchanged unless the task
explicitly includes reviewed song-data edits.

For work that needs architecture or implementation planning, continue the
saved `codex-with-chatgpt` session for workspace `HOPAMTHANHCA` and use the
connector named `Codex with ChatGPT · HOPAMTHANHCA`. Do not paste repository
files, diffs, or command logs into ChatGPT; it can read them through the
connector.
